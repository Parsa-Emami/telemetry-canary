# Security

The project is in proof-of-concept stage. Security fixes target the current main branch.

Report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/Parsa-Emami/telemetry-canary/security/advisories/new) when it is available. If that page is unavailable, contact the [maintainer](https://github.com/Parsa-Emami) privately. Include the revision, affected component, impact and sanitized behavior. Keep credentials and production evidence out of all reports.

The [threat model](docs/threat-model.md) covers the current boundary.
